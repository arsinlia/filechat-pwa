# چت با فایل — وب‌اپ قابل نصب (PWA)

فایل‌ها (PDF، Word، Excel، PowerPoint، متن/کد، تصویر، صوت/ویدیو) را می‌خوانَد و با API key شما درباره‌شان گفتگو می‌کند.
بدون سرور و بدون build؛ فقط فایل‌های استاتیک.

## فایل‌ها
index.html، app.js، app.css، sw.js، manifest.webmanifest، پوشه‌ی icons

## میزبانی (باید HTTPS باشد تا قابل نصب شود)
هر کدام از این‌ها رایگان است:
- **Netlify Drop**: به app.netlify.com/drop بروید و کل پوشه را بکشید و رها کنید.
- **GitHub Pages**: فایل‌ها را در یک مخزن بگذارید و Settings > Pages را روی شاخه‌ی main فعال کنید.
- **Cloudflare Pages / Vercel**: پوشه را به‌عنوان پروژه‌ی استاتیک (بدون build) آپلود کنید.

تست محلی روی کامپیوتر: داخل پوشه `python3 -m http.server 8080` و بعد باز کردن http://localhost:8080

## نصب روی گوشی
- Android Chrome: منوی ⋮ ← Install app (یا دکمه‌ی «نصب برنامه» داخل خود برنامه)
- iPhone Safari: دکمه‌ی Share ← Add to Home Screen

## نکات
- Base URL، کلید و مدل را از ⚙ وارد کنید. کلید فقط در localStorage همین مرورگر می‌ماند.
- درخواست‌ها مستقیم از مرورگر به API می‌روند؛ سرویس‌دهنده باید CORS را اجازه بدهد (OpenAI، OpenRouter، Anthropic و Gemini اجازه می‌دهند).
- کتابخانه‌های خواندن PDF/Word/Excel/PPTX هنگام اولین استفاده از cdnjs بارگذاری و برای دفعات بعد کش می‌شوند.
- در Android Chrome، بعد از نصب، در منوی «اشتراک‌گذاری» سیستم هم می‌توانید این برنامه را برای دریافت فایل انتخاب کنید.
- هر پیام، متن فایل‌های قبلی گفتگو را هم دوباره می‌فرستد؛ برای فایل‌های بزرگ «گفتگوی جدید» بزنید.
